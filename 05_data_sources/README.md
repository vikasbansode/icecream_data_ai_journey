# Phase 05 — Data Sources

**Source-first rule:** this folder contains only source representations. Do not put `dim_*` or `fact_*` files here.

Sources include SQLite POS transactions, CSV customer/store/weather, Excel product catalog, XML supplier catalog, website HTML, API JSON, Parquet, Arrow, sensor data and reference data.

Dimensions and fact tables are created only in Phase 13 Data Modeling.
