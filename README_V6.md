# Ice Cream Business — Data Journey V6

## Scope
This package ends at **Data Analysis & BI Automation**. It does not include machine learning, deep learning, GenAI, RAG, AI agents, agentic AI or multi-agent AI.

## Core journey
01 Business Understanding → 02 Business Questions → 03 Data Requirements → 04 Requirement Gathering → 05 Data Sources → 06 Source Data Discovery → 07 Data Collection → 08 Data Ingestion → 09 Raw → 10 Cleaning → 11 Staging → 12 Transformation → 13 Data Modeling → 14 Data Warehouse → 15 Data Mart → 16 Technical Data Discovery → 17 Data Analysis → 18 Visualization → 19 BI & Reporting → 20 Data Analysis & BI Automation.

## Source-first rule
`05_data_sources` contains source data only. Dimensions and facts are created later and live in the warehouse/data-modeling stages.

## Practical rule
Every phase includes context, real files, code, examples, exercises and expected outputs. Analysis includes DuckDB SQL joins across fact and dimension tables.
