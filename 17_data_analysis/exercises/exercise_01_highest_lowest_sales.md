# Exercise 01 — Highest and Lowest Sales Day

## Problem
Management wants to know the best and worst sales day.

## Tasks
1. Load the five warehouse CSV files into DuckDB.
2. Join `fact_sales` to `dim_date`.
3. Calculate daily sales.
4. Return the highest sales day.
5. Return the lowest sales day.
6. Return both date and amount.
7. Explain why `fact_sales` alone is not enough to display the calendar date.

## Files
Use the files in `../data/`.

## Expected output
A result containing date and total_sales for highest and lowest days.

## Student requirement
Write the SQL yourself.
