# Exercise 04 — Detect a Significant Sales Drop

## Problem
Management says sales suddenly dropped and wants the first date where sales fell by more than 20% compared with the previous day.

## Tasks
1. Calculate daily sales.
2. Use `LAG()` to get the previous day's sales.
3. Calculate percentage change.
4. Filter drops greater than 20%.
5. Return the first occurrence.
6. Explain the result.
